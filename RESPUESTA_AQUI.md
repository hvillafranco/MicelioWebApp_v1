### **2️⃣ CLAUDE OPUS (Anthropic)**

#### **AQUÍ en GitHub Copilot Workspace:**
```
Tú pides algo → Claude analiza TODO el repo → Edita múltiples archivos → Ejecuta tests → Hace commit
```
- 🤖 **Agente autónomo**: Trabaja solo con supervisión
- 📂 **Ve TODO**: Todos los archivos del proyecto
- ✏️ **Edita directamente**: No necesitas copy-paste
- 🧠 **Inteligente**: Análisis profundo y contextual
- 🔧 **Ejecuta comandos**: bash, git, tests, etc.

**Ejemplo:**
```markdown
Tú: "Añade visualización del Genoma Miceliar con los 4 valores éticos"

1. Lee micelio-data.js
2. Lee fractal-viewer.js  
3. Lee LOG_INSTRUCTIVO para entender contexto

5. Actualiza README.md
6. Hace commit de los cambios

```

#### **En claude.ai (su plataforma):**
```
Tú escribes → Claude responde → TÚ copias → TÚ pegas → TÚ guardas
```
- 💬 **Solo chat**: No toca tu código
- 📎 **Subes archivos**: PDFs, documentos, etc.
- ✂️ **Copy-paste manual**: Tú haces todo
- 🔀 **Cambio de contexto**: Sales del editor
- 📱 **Más flexible**: Funciona en móvil
